# Flashcards

## JAMF / BigFix Basics

Q: What is JAMF Pro usually used for?  
A: Managing Apple/macOS devices, including inventory, policies, profiles, enrollment, and device-management workflows.

Q: What is BigFix usually used for?  
A: Endpoint management, inventory, patching, compliance, and reporting across fleets of devices.

Q: What is MDM?  
A: Mobile Device Management. It lets an organization manage device settings, enrollment, security policies, and software deployment.

Q: What is patch compliance?  
A: Whether devices have required operating-system or application updates installed.

Q: What is API authentication?  
A: A way for software to prove it is allowed to access an API.

Q: What is a bearer token?  
A: A temporary access token sent in an API request header to authorize calls.

Q: What is an environment variable?  
A: A setting stored outside code, often used for secrets or deployment configuration.

Q: Why should secrets not be committed to GitHub?  
A: Anyone with repository access could steal them and access real systems.

Q: What is mock data?  
A: Fake but realistic sample data used to test and demonstrate a system safely.

Q: What does Docker do in this project?  
A: Packages the app so it runs the same way on another machine.

## Interview Truth Cards

Q: Can I say I have years of JAMF experience from this?  
A: No. Say you built a JAMF API lab project.

Q: Can I say I have years of BigFix experience from this?  
A: No. Say you built a BigFix REST/query lab project.

Q: What can I truthfully say?  
A: You built a Dockerized endpoint-compliance lab with JAMF/BigFix-style API clients, mock data, normalization, and an HTML dashboard.

Q: Why is this useful for an endpoint role?  
A: It shows initiative, API literacy, reporting logic, endpoint vocabulary, and safe handling of credentials.

Q: What is the strongest sentence?  
A: "I built this to close a known gap and learn the API/reporting pattern before entering an endpoint team."
