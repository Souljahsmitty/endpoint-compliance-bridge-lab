# Truthful Talking Points

## Resume Bullet

Built a Dockerized endpoint-compliance lab that models JAMF Pro and BigFix API integration patterns, normalizes mock device/patch data, and presents a simple HTML dashboard with safe environment-variable configuration.

## Stronger Project Description

Created a small endpoint-compliance bridge to understand how Apple/macOS inventory from JAMF Pro and patch/compliance status from BigFix can be normalized into one reporting view. The project includes mock mode, API client structure, Docker packaging, and documentation for recruiter/interview discussion.

## Recruiter Screen Version

"I saw JAMF and BigFix were common gaps in endpoint roles, so I built a small lab around the API pattern. It is not production administration experience, but it helped me understand the vocabulary, authentication flow, endpoint inventory shape, patch-compliance reporting concept, Docker packaging, and how to document the work."

## What Not To Say

- "I have years of JAMF administration."
- "I have years of BigFix administration."
- "I deployed production patches with BigFix."
- "I managed Apple Business Manager enrollment."
- "I administered Intune compliance policies."

## What To Say Instead

- "I built a lab integration."
- "I studied the API flow using official docs."
- "I used mock data because I did not have an enterprise tenant."
- "I can explain the basic inventory/compliance reporting pattern."
- "I would still need hands-on production ramp time with JAMF Pro, BigFix, Intune, and Apple Business Manager."

## IQ200 Rule

The smart move is not pretending the gap vanished.

The smart move is making the gap smaller, visible, and defensible.
